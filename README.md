# Novo N1 Burger Club · RE:MENU (Tastefy, 2026)

Protótipo navegável do novo cardápio do N1 Burger Club no layout do app próprio da Tastefy, com o filme de lançamento e a justificativa com dados de conversão, preço e ticket.

- `index.html` — abre o site (funciona direto no navegador ou pelo GitHub Pages).
- `menu-data.js` — o cardápio (preços, custos com saco kraft, descrições, grupos do modal).
- `video/n1-lancamento.mp4` — filme de lançamento (sem locução).

Imagens marcadas como ilustrativas foram geradas por IA a partir das fotos reais da marca. Números da rede são referência interna; metas são projeção.
